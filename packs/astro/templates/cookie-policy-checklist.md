## Consent Behavior

- [ ] Optional categories start denied.
- [ ] Accept, reject, and configure controls are equally accessible.
- [ ] No optional tag/request/storage occurs before valid consent under the selected profile.
- [ ] Preferences persist with the Policy version.
- [ ] Users can reopen settings and revoke consent.
- [ ] Project-controlled optional storage is removed where technically possible after revocation.
- [ ] Remaining provider-controlled behavior is explained.

## Analytics Data Minimization

- [ ] Event taxonomy is approved and versioned.
- [ ] No secrets, direct identifiers, sensitive data, or form values are sent.
- [ ] URLs and query parameters are allowlisted or sanitized.
- [ ] Network/storage evidence matches this inventory.
